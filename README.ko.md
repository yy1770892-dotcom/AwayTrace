<h2 align="center">자리를 비우기 전, 내 PC의 보호를 시작하세요.</h2>

회의, 점심, 잠깐의 외출처럼 PC를 두고 자리를 비워야 할 때가 있습니다.

AwayTrace는 그동안 중요한 폴더에 변경이 있었는지 기록하고, 지정한 폴더와 메신저 화면을 보호하는 Windows 10/11용 개인 프라이버시 앱입니다.

누군가를 촬영하거나 행동을 추적하지 않습니다. 파일 내용, 키 입력, 화면, 메신저 대화도 기록하지 않습니다. 사용자가 직접 보호를 시작한 자기 PC에서 **파일 변경과 PC 활동의 정황**만 확인합니다.

## AwayTrace는 이렇게 작동합니다

### 1. 보호할 대상을 정합니다

폴더는 목적에 따라 나누어 등록할 수 있습니다.

- **기록 폴더:** 파일 생성, 수정, 삭제, 이름 변경 정황을 기록합니다.
- **잠금 폴더:** 기록과 함께 Windows 권한을 이용해 폴더 접근을 차단합니다.
- **메신저 보호:** 실행 중인 메신저나 업무 앱의 창을 숨기거나 앱을 종료합니다.

필요한 기능만 선택할 수 있으며, 폴더를 잠그지 않고 변경 기록만 남기는 것도 가능합니다.

### 2. 자리를 비우기 전 보호를 시작합니다

보호를 시작하면 선택한 폴더의 변경 기록이 시작되고, 잠금 폴더와 등록 앱에 설정한 보호 방식이 적용됩니다.

원한다면 보호 시작과 함께 Windows 화면 잠금도 실행할 수 있습니다. 보호 중에는 창을 숨겨도 AwayTrace가 백그라운드에서 계속 작동합니다.

### 3. 돌아온 뒤 기록을 확인합니다

PIN으로 보호를 종료하면 해당 시간의 자리비움 리포트가 열립니다.

무엇이 언제 바뀌었는지 시간순으로 확인하고, 변경이 없었다면 그대로 "파일 변경 없음"을 확인할 수 있습니다.

## 돌아온 뒤, 한눈에 확인하세요

<p align="center">
  <img src="docs/screenshot-report.png" width="720" alt="AwayTrace 자리비움 리포트" />
</p>

자리비움 리포트는 보호를 시작한 시각부터 종료한 시각까지 관찰된 기록을 하나의 흐름으로 보여줍니다.

- 파일 생성, 수정, 삭제, 이름 변경
- 보호 시작과 종료
- Windows 잠금과 잠금 해제
- 등록한 메신저와 업무 앱의 보호 처리
- 감시 도중 발생한 오류와 기록 공백

이벤트 유형별로 필요한 내용만 골라 볼 수 있으며, 기록은 CSV 또는 JSON 파일로 내보낼 수 있습니다.

앱이 비정상적으로 종료되거나 기록이 중간에 끊긴 경우에는 정상적인 결과처럼 표시하지 않습니다. 해당 리포트에 **"기록 신뢰도 낮음"**을 표시해 기록에 공백이 있을 수 있음을 알려줍니다.

이 리포트는 파일 변경 정황을 정리한 참고 기록입니다. 누가 파일을 변경했는지, 파일을 열어보거나 복사했는지를 증명하지는 않습니다.

## 중요한 폴더를 두 가지 방식으로 관리하세요

<p align="center">
  <img src="docs/screenshot-main.png" width="720" alt="AwayTrace 메인 화면" />
</p>

**기록 폴더**는 접근을 막지 않습니다. 평소처럼 사용할 수 있으며 보호 중 발생한 파일 변경 정황만 기록합니다.

**잠금 폴더**는 Windows의 NTFS 권한을 이용해 현재 사용자의 접근을 차단합니다. 보호가 끝나면 원래 사용할 수 있도록 권한을 되돌립니다.

잠금 상태는 PC를 재부팅해도 유지됩니다. 재부팅 후 자동 복구 옵션을 사용하면 Windows 로그인 뒤 이전 보호 세션을 다시 이어갈 수 있습니다.

## 메신저 화면도 함께 보호하세요

카카오톡이나 업무용 메신저처럼 화면 노출이 걱정되는 앱을 등록할 수 있습니다.

- **창 숨기기:** 앱은 실행된 상태로 두고 화면에 보이는 창을 숨깁니다.
- **앱 종료:** 등록한 앱이 실행되면 해당 프로세스를 종료합니다.
- **그대로 두기:** 메신저 보호를 적용하지 않고 파일 기록 기능만 사용합니다.

창 숨기기 방식으로 보호한 앱은 보호 종료 후 다시 표시됩니다. 앱 종료 방식을 사용한 경우 종료된 앱을 자동으로 다시 실행하지는 않습니다.

AwayTrace는 메신저와 공식 연동하지 않습니다. Windows에서 실행 중인 앱의 창과 프로세스를 기준으로 작동하며, 대화 내용이나 읽음 여부는 확인하지 않습니다.

## PC 사용 정황도 함께 확인하세요

AwayTrace는 Windows 시스템 기록을 참고해 PC가 켜지고 꺼진 것으로 추정되는 시각과 비정상 종료 기록을 보여줍니다.

평소 사용하는 시간을 지정하면 그 시간 밖에서 발견된 기록을 구분해 볼 수도 있습니다. AwayTrace 실행과 정상 종료 기록도 함께 표시되어, 설명하기 어려운 기록 공백을 살펴보는 데 도움을 줍니다.

PC 사용 기록은 Windows 이벤트 로그를 정리한 참고 정보입니다. 절전 진입과 복귀를 포함한 모든 활동을 완전하게 기록하는 기능은 아닙니다.

## 보호 설정은 PIN으로 관리합니다

AwayTrace의 PIN은 Windows 로그인 비밀번호와 별도로 설정합니다.

PIN은 평문으로 저장하지 않고 PBKDF2-HMAC-SHA256 방식으로 해시하여 로컬에 저장합니다. PIN을 5회 연속 잘못 입력하면 30초 동안 다시 시도할 수 없습니다.

전역 단축키를 사용하면 AwayTrace 창, 작업표시줄 표시, 트레이 아이콘을 한 번에 숨기고 같은 단축키로 다시 표시할 수 있습니다. 이 기능은 화면 표시만 숨기며, 작업 관리자에는 AwayTrace 프로세스가 나타납니다.

## 기록은 내 컴퓨터 안에만 남습니다

AwayTrace에는 계정 가입이나 로그인 과정이 없습니다.

서버와 클라우드를 사용하지 않으며, AwayTrace가 기록을 외부로 전송하지 않습니다. 앱의 설정과 기록은 다음 위치의 SQLite 데이터베이스에 저장됩니다.

```text
%LocalAppData%\AwayTrace\awaytrace.db
```

저장되는 정보는 보호 세션, 등록 폴더, 관찰된 파일 이벤트, 보호 앱 설정, PC 사용 정황입니다. 파일 내용 자체는 저장하지 않습니다.

소스코드는 모두 공개되어 있습니다. 어떤 정보를 기록하고 어떻게 저장하는지 이 저장소에서 직접 확인할 수 있습니다.

## 기록하지 않는 정보

AwayTrace는 다음 정보를 수집하거나 기록하지 않습니다.

- 파일 내용과 파일 해시
- 키 입력과 클립보드
- 화면과 스크린샷
- 웹캠과 마이크
- 메신저 대화와 읽음 여부
- 파일을 열거나 읽은 기록
- 파일을 복사했다는 기록
- 사용자나 행위자의 신원

AwayTrace는 직원 감시, 침입자 식별, 포렌식 조사 또는 법적 증거 수집을 위한 프로그램이 아닙니다.

## 정확히 알아둘 점

AwayTrace가 기록하는 것은 **관찰된 파일 변경 정황**입니다. 파일이 생성, 수정, 삭제되거나 이름이 바뀌면 기록할 수 있지만, 단순히 파일을 열거나 읽고 복사한 행동은 확인할 수 없습니다.

잠금 폴더에 대한 접근은 Windows가 차단합니다. 다만 누군가 잠긴 폴더를 클릭하거나 접근을 시도했다는 사실은 현재 버전에서 기록하지 않습니다.

메신저 창 보호는 등록한 앱을 일정 간격으로 확인해 적용합니다. 앱이나 PC 상태에 따라 창이 잠시 나타난 뒤 숨겨질 가능성이 있으며, 전문 보안 프로그램과 같은 완전한 차단 기능은 아닙니다.

PC가 꺼져 있거나 AwayTrace가 실행되지 않는 동안에는 파일 변경을 기록할 수 없습니다. 또한 PC의 관리자 권한을 가진 사용자는 폴더 권한을 변경하거나 앱을 종료하거나 삭제할 수 있습니다.

이러한 이유로 AwayTrace는 파일 열람이나 침입을 증명하는 도구가 아니라, 자리를 비운 동안의 변경 정황을 확인하고 중요한 정보의 노출을 줄이기 위한 개인용 도구입니다.

## 설치

1. [최신 릴리스](../../releases/latest)에서 `AwayTrace.exe`를 다운로드합니다.
2. 다운로드한 파일을 실행합니다.
3. 처음 실행할 때 AwayTrace 전용 PIN을 설정합니다.

별도의 설치 과정이나 .NET 런타임 설치는 필요하지 않습니다.

AwayTrace는 현재 코드 서명이 적용되지 않은 개인 오픈소스 앱입니다. 처음 실행할 때 Windows SmartScreen이 "알 수 없는 게시자" 경고를 표시할 수 있습니다. 배포 출처와 파일을 확인한 뒤 `추가 정보`에서 실행 여부를 결정하세요.

## 사용 전 확인해 주세요

AwayTrace는 Windows 10/11 전용 프로그램입니다.

사용자 본인이 소유하거나 관리 권한을 가진 PC에서 개인 프라이버시 보호 목적으로 사용하세요. 다른 사람의 PC에 동의 없이 설치하거나 감시 목적으로 사용하는 것은 AwayTrace의 제작 목적과 맞지 않습니다.

## 개발자와 검토자를 위한 정보

요구 사항: Windows 10/11, .NET 8 SDK

```powershell
dotnet build
dotnet test
dotnet run --project src\AwayTrace.App\AwayTrace.App.csproj
```

자체 포함 단일 실행 파일 만들기:

```powershell
cd src\AwayTrace.App
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none
```

주요 로컬 데이터 테이블:

```text
settings
monitored_folders
sessions
file_events
protected_apps
pc_usage_events
```

`file_events`에는 시각, 이벤트 유형, 경로, 이전 경로와 세션 ID만 저장됩니다. 파일 내용은 저장하지 않습니다.
